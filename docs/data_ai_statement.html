数据与 AI 使用说明

本项目使用公开资料和本地统计学习代码，当前用途是降雨参考事件的离线方法实验与准备成本解释。没有采购设备、接入校方后勤数据或收集个人信息。

模型和工具

在线天气和冻结实验分别保存。Python 在线缓存位于 runtime/weather，含原始响应、内容摘要、获取时刻和按来源核查的完整度；文件按内容保存，最后原子替换索引。HTML 在浏览器本地保存缓存。新鲜度按获取时刻计算，预报超过 3 小时、背景与站点参考超过 24 小时会标为过期；获取时刻不等于天气模型初始化或官方发布时间。

两入口的联网行为不同：搬货决策首页会自动获取杭州集合天气，并在可用时复用缓存；研究工作台的“最新天气”页仍需用户点击刷新才连接固定官方接口。超时、限流、单位不符、错站、重复时间或坏响应不会替换有效缓存。缺少降水小时的 24 小时窗口不计算完整累计，也不补零。集合成员占比只描述数值预报内部频率，不是货损概率；Forecast API 来源也不能冒充 ensemble。交付附带一份真实获取、可重新核对原始响应的天气快照，按其自身时间显示；它不会在离线打开时伪装成刚刚更新。

AI、视频与人工工作

AI 的拟定任务是将数值预报输入映射成达到研究降水阈值的概率，并与简单方法在相同测试日上比较。模型和模型选择通过冻结配置离线执行，实际版本与结果以 reports/evaluation.json 和 reports/experiment_run.json 为准。页面不会临时训练、挑选测试阈值或生成没有来源的预测。

Codex 协助检索公开入口、编写解析、测试、应用和材料草稿。代码使用 Python、pandas、NumPy、scikit-learn、Streamlit 和 Plotly；当前阶段不需要 OpenAI API 密钥，也不把语言模型的文字判断当作降雨数据。人工团队仍需核对正式提交信息、用户假设和最终论述。

当前选定的宣传片为 73.866666667 秒、1920×1080、30fps、2216 帧、10 个场景。画面由程序逐帧生成并通过 WebCodecs 编码，没有使用截图、录屏或外部图片视频作为画面输入。影片只有一条 AAC 音轨，不含旁白或其他配音。配乐为 Young Visionaries - Eric Matyas，使用 Soundimage International Public License；署名为 Music by Eric Matyas / www.soundimage.org，来源页为 soundimage.org/techno/，许可页为 soundimage.org/sample-page/。原曲裁切区间为 17.313872945628-91.180539612295 秒，原速原调、连续裁切、首尾淡变，无循环。Codex 协助检索公开入口、分镜、动画、测试、导出和材料整理；团队仍需完成人工观看、听审与线上核验。源工程和第三方库许可随 media/latest/source/ 提供。
