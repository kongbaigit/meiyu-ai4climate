# 三分钟答辩讲稿

用于团队口头演练，配合当前约74秒的完整宣传片；尚未进行真人模拟答辩。建议先计时朗读一次，再按实际语速删减，不加快到听不清。

## 0:00-0:25｜问题

我们做的是“梅雨有数”，面向杭州需要整理易受潮货物的小商户。连续雨水会影响部分商品品质和储运，但天气数字与准备成本之间，还缺少容易理解的解释。我们想验证：使用者能否读懂降雨的不确定性，了解不同准备成本怎样影响选择。当前用户需求仍待实际访谈。

## 0:25-1:00｜演示

这里选择2025年6月1日08:00开始的历史窗口。模型估计参考日降水达到25毫米的概率约为67.9%。准备成本设置为10单位，它是假设相对值，不是人民币。揭晓后，SSOD参考日降水是29毫米。页面保留时间窗口、来源和限制，让观众可以核查同一次判断。

## 1:00-1:40｜AI与证据

AI承担的是把公开数值预报映射为参考降雨事件概率，使用的是小型逻辑回归。我们按时间分开训练、验证和测试，只在验证段选择模型。主实验有636个配对日；测试240日、18个事件。选中模型的测试Brier为0.0455，训练事件率基线的测试Brier为0.0697。模型提供概率表达，没有增加原始雨量的排序能力。

## 1:40-2:15｜失败与限制

在固定10%情景阈值下，模型漏报6次、误报9日；原始25毫米规则漏报11次、误报4日。少漏报伴随更多误报。另一个案例，7月18日模型只有约2.8%，参考日降水却达到101.8毫米。因此低概率不能保证安全，降雨概率也不是门店积水概率。

## 2:15-2:40｜数据边界

最新天气把数值预报、ERA5背景和站点参考分开展示，更新失败保留旧缓存。2026年独立检查只有85个配对日、1个事件，缺少4月至9月完整参考；宁波没有迁移指标。我们保留这些缺口，不用ERA5补成站点标签。

## 2:40-3:00｜下一步

90天内先做5至8人的理解测试，再核实真实预报何时可获得，开展影子运行。当前没有实测避损或付费证据。我们的交付是可运行、可追溯的研究原型，以及明确的验证步骤。
