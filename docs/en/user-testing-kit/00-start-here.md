# Meiyu Prepare User-Testing Kit

**Version:** `UT-20261016-v1`  
**Status:** prepared, not recruited or conducted. About 10 minutes per person; planned 5-8 volunteers. This kit tests prototype comprehension and operation, not forecast skill, avoided loss, or market demand.

## Use order

1. Read this page, the host script, and scoring rules. Fill the date, record custodian, and withdrawal deadline.
2. Use the recruitment page; the invitation is a draft and has not been sent.
3. Run one internal rehearsal as R01 for flow and timing only; do not count it as a formal result.
4. Copy one blank individual record per formal participant, P01, P02, and so on. Give participants only the task card and demo; do not give scoring rules, answers, or the full host kit.
5. Follow the fixed order: record first answers, then explain; complete the aggregation and remediation template the same day.
