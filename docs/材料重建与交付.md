## 项目说明的排版源

编辑 `templates/submission/参赛项目说明.html` 及同目录配图，不要只修改 `docs` 中的生成结果。项目说明保留冻结实验事实、数据限制、AI 使用和团队信息待填状态；没有训练或在线请求。

先生成 HTML 和 Markdown，确认内容及公式，再生成 PDF：

```powershell
python -m src.submission --output build/说明内容检查
python -m src.submission --output build/说明PDF检查 --pdf --font C:/Windows/Fonts/simhei.ttf
```

PDF 需要 `reportlab`、`pypdf`、`Pillow` 和支持中文的 TTF 字体。输出只写入 `build` 下尚不存在的独立目录；生成后渲染每页检查文字、表格、公式、页脚和图片，再同步确认过的候选文件。

## 工程包

```powershell
python -m src.package --root . --output dist/梅雨有数_工程_新版本.zip
```

工程包包含源码、模板、公开数据快照、冻结结果、当前材料和必要评估报告；`build`、`dist`、运行缓存不进入包。打包后检查 ZIP CRC、逐文件摘要、包内字节和当前源码一致性。

ZIP 是可复现工程候选包，不是已发布网址或已提交凭证。公开部署和报名按 `docs/提交清单.md` 执行。
