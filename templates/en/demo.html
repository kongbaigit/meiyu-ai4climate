Reproduction path

This HTML reads packaged frozen results; it does not fit a model in the browser. The full Python project provides raw snapshots → data checks → time split → training and validation selection → frozen predictions → NumPy parameter reconstruction.

Rebuilding all 2,544 probabilities from JSON parameters and NumPy has a maximum absolute error of about 2.8 × 10−16. That tests calculation identity, not new external effect validation.

What to validate next

Move the demonstrable prototype toward an evidenced tool.

Small merchants are a user hypothesis to validate. There are no interviews, real-loss records, carbon measurements or production-use data yet. The 90-day plan starts with understanding and data availability.

90-day validation roadmap · not yet run

Weeks 1–2

Confirm the user hypothesis; plan voluntary recruitment

Invite 5–8 participants to try the prototype remotely. Check whether preparation explanations meet a need, explain questions and withdrawal first, and report missing user evidence if recruitment fails.

Deliverable: recruitment note, user hypothesis, continue-or-narrow decision.
Weeks 3–4

Run an understanding test with fixed historical cases

Check whether people can explain the probability object, cost assumption, reference-day boundary and non-flooding meaning. Do not expose participants to real weather risk.

Deliverable: anonymous completion notes and misunderstanding list.
Weeks 5–8

Verify when a real forecast is available; start shadow operation

Keep initialization, public availability, fetch time and complete-hour records. If source or hours are missing, stop the judgment. Fix evaluation rules before adding independent data.

Deliverable: forecast-time evidence, failure log and independent evaluation protocol.
Weeks 9–12

Review mistakes and run a second understanding test

Check whether misunderstandings fall, users want to continue and data support expansion. Economic benefit requires actual records; it is not inferred from a hypothetical curve.

Deliverable: trial report and next monsoon-season validation plan.

A mid-October start puts most of 90 days in autumn and winter; it cannot validate a full next monsoon season. 80% understanding and a three-minute completion time are planning targets.

Why continue this direction?

Public market monitoring in Zhejiang records impacts of persistent rain on some goods, harvest and storage. This prototype turns “how much rain” into an explainable probability and lets the user see how preparation cost changes the choice.

This is a climate-adaptation tool to validate. Two years at one station cannot establish a climate trend, and carbon benefit has not been measured.
