# 当前代码与材料入口

以下路径均相对`meiyu`。改生成文件时先改模板或源码，保留冻结文件。

| 功能 | 修改入口 | 生成或检查 |
| --- | --- | --- |
| Python应用及历史体验 | `app.py`、`src/product_views.py` | 重启应用并检查对应页面 |
| 在线三源和完整度 | `src/online_views.py`、`live_data.py`、`data_completeness.py` | 对应测试；联网只由用户点击触发 |
| 离线应用 | `templates/offline.html`、`live_client.js`、`live_client.css` | `python -m src.offline`；检查桌面与手机 |
| 数据、实验与结果读取 | `src/contracts.py`、`data_pipeline.py`、`experiments.py`、`results.py` | 改实验另存版本；只读核验用`src.verify`与`src.reproduce` |
| 四页项目说明 | `templates/submission/参赛项目说明.html`及配图 | `src.submission`输出到build新目录；PDF逐页检查后同步docs |
| 其他提交材料 | `docs`对应Markdown | 独立维护；旧`src.materials`已禁用，不会更新草稿 |
| 影片、旁白、配乐 | `media/native_source` | 详细步骤见其README；影片截图仅用于检查 |
| 静态材料站 | `templates/materials_portal.html`、`portal.css`、`downloads.js`、`src/site_release.py` | 先打工程ZIP，再用`--source-zip`生成站点并检查 |
| 用户测试执行包 | `docs/用户测试执行包`、`tools/build_user_test_pack.py` | 固定版本与评分，打包检查；真实记录不入此目录 |
| 标准工程ZIP | `src/package.py` | 白名单打包源码/材料/原始数据，不含本机环境和内部旧稿 |
| 完整队友接手包 | `tools/build_teammate_handoff.py`、`templates/handoff` | 生成当前工程、站点、接手说明和清单，核验冻结与ZIP |

`data`和`artifacts`为主实验；`external/hangzhou_2026`为独立时间段；`external/live_seed`为在线交付快照；运行后的天气缓存保存在`runtime`。三种证据不能混成同一实验结果。
