# 运行、核验与重建

## 先核验，再运行

在解压根目录（与`meiyu`并列）运行：

```powershell
python tools/verify_current_handoff.py
python tools/verify_handoff.py --frozen-only
```

只使用Python标准库，不联网、不训练。本次全文件身份由`delivery_manifest.json`管理；旧`handoff_manifest.json`保留历史字节，不能拿其全文件条目要求新说明恢复旧版。

双击`meiyu/demo.html`查看应用，双击`meiyu/media/demo.html`或`demo.mp4`查看影片。可离线看历史案例，只有点击天气更新才请求接口。

## 完整Python应用

Windows安装Python 3.13后运行`meiyu/start.cmd`，首次创建虚拟环境并安装`requirements.txt`，需要网络。默认地址`http://127.0.0.1:8513`，不能把它当评委可访问的网址。其他系统及手动命令见`meiyu/README.md`。本次打包没有在另一台电脑重新验证安装。

环境准备好后，在根目录运行只读数据和参数复现：

```powershell
.\meiyu\.venv\Scripts\python.exe tools/acceptance.py --output 接手验收_新记录.json
```

报告文件必须尚不存在且位于`meiyu`之外。真实失败要保留；历史测试通过不代表新环境自动通过。

## 本地静态材料站

在根目录运行，再用浏览器打开显示的网址：

```powershell
python -m http.server 8540 --bind 127.0.0.1 --directory meiyu/site/dist
```

打开`http://127.0.0.1:8540/`。材料首页、影片、说明及工程/影片分段下载已在本次构建中校验来源；下载按钮依赖本地HTTP或正式HTTPS，不要在压缩软件或`file://`下判断下载能力。手机访问和公网访问仍需实际托管后的检查。

## 修改与重新交付

以下命令在`meiyu`目录运行。PDF步骤详见`docs/材料重建与交付.md`，先HTML再导PDF并逐页检查；旧材料生成器已经停用。

```powershell
python -m src.submission --output build/说明_新版本
python -m src.package --root . --output dist/梅雨有数_工程_新版本.zip
python -m src.site_release --source-zip dist/梅雨有数_工程_新版本.zip
python -B tools/build_user_test_pack.py
python -B tools/build_teammate_handoff.py
```

`src.site_release`和完整接手打包额外需要`markdown`；缺失时在团队环境安装该构建依赖。PDF另需`reportlab`、`pypdf`、`Pillow`及中文字体，影片重建环境见`media/native_source/README.md`。日常运行应用不要求安装全部制作工具。

完整接手打包会生成带时间戳的新ZIP并保留旧输出；使用本次源码重建，不依赖旧静态站或原电脑的Sites绑定。它读取本包已附的历史检查记录及六冻结基线，不上传任何文件。修改任务协议或实验后，应先更新版本与核验规则，再交付新版本，不能沿用旧审查结论。
