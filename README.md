## 在这台 Windows 电脑启动完整应用

双击本目录的 **start.cmd** 可启动新版搬货决策应用，默认打开 [本地应用](http://127.0.0.1:8532)。首次启动会创建独立 `.venv-decision` 并安装锁定依赖，需联网。关闭终端或按 Ctrl+C 停止服务。

完整研究工作台使用 **start.ps1**，默认打开 [本地应用](http://127.0.0.1:8513)。两个启动入口分别对应不同依赖和端口。

也可以在 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\setup.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1
```

默认端口 8513。如被其他程序占用，可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File .\start.ps1 -Port 8514`。启动脚本不自动改变系统默认浏览器。

演示配置关闭了源码热更新。修改 Python 源码后，先停止再启动应用，确保跨模块接口一起刷新。

本机通过验证的环境为 Python 3.13.12；完整依赖版本在 requirements.txt。其他电脑建议安装 Python 3.13，再执行上述命令。本机地址仅在运行电脑可访问；公开访问使用上方 GitHub Pages 地址。

## 怎么看成果

1. **最新天气**：杭州与宁波的7日预报、ERA5背景和站点参考覆盖；查看完整度日历、字段覆盖和缺口，手动获取最新数据。
2. **历史演示**：选择测试段窗口，查看概率，调整假设准备成本，再揭晓参考日降水。默认显示 2025 年 6 月；月份不冒充官方梅雨起止期。
3. **方法比较**：看相同测试日的基线、模型、重采样区间、情景成本和失败案例。
4. **数据核查 / 样本浏览**：看来源、缺测、排除原因、UTC 日界与原始参考量，下载规范样本。
5. **模型接入**：检验队友或后续实验的 CSV 协议；协议通过不表示模型效果通过验证。

## 冻结实验

事件定义为参考日降水达到 25 毫米。训练段为 2024 年，验证段为 2025 年 1—4 月，测试段为 2025 年 5—12 月，分别有 276/120/240 个日窗口和 16/3/18 个参考事件。只在验证段选择 C 和方法，测试段不调参。

| 方法 | 测试 Brier，越小越好 |
| --- | ---: |
| 训练期固定事件率 | 0.0697 |
| 原始预报 25 毫米规则 | 0.0625 |
| 验证选中的降水概率模型 | 0.0455 |
| 降水与温湿度模型 | 0.0444 |

温湿度模型测试分数虽更低，验证未选中；应用保留验证选定的降水模型。原始规则是确定性 0/1 指示量，不是天气机构的概率产品。样本和事件仍少，部分概率箱存在低估，不把较低 Brier 写成稳定运营能力。

补充检查显示，原始连续雨量与降水概率模型的 ROC-AUC 相同，为 0.9712；模型保持雨量排序，提供概率映射。5—7 月固定月份子集为 90 日、16 个事件，选中模型 Brier 为 0.1038，对照为 0.1605 和 0.1333。补充检查不参与调参，也不是新的盲测。宁波机场迁移检查因 362 行参考降水全部缺失而停止，未生成迁移效果。

另按下载前保存的内部协议检查了2026年1—9月。273个配置日只有85个完整配对日、1个事件，完整参考仅覆盖1—3月，4—9月缺少完整参考。这项检查没有补上新梅雨季验证，分数只作描述；四种冻结方法、逐月覆盖、全部指标和来源均另存于 reports/temporal_validation.json 与 external/hangzhou_2026，不混入主实验。内部协议不是第三方公开预注册，所有模型参数保持不变。

成本曲线是假设准备完全避免相关损失的相对成本情景，不是实测人民币成本、真实灾损或减排量。

## 核验与复现

以下命令都在本目录运行。包内包含主表、模型结果和原始来源快照，无需为了演示重新下载。

```powershell
# 核对主表、CSV/Parquet、来源快照与关联；不修改样本。
.\.venv\Scripts\python.exe -m src.verify --output reports/integration_checks.json

# 通过JSON参数和NumPy重建预测，独立重算Brier/混淆矩阵；不训练。
.\.venv\Scripts\python.exe -m src.reproduce

# 复用已冻结且散列一致的结果；不同身份或损坏文件会报错。
.\.venv\Scripts\python.exe -m src.experiments run

# 在工作区专用临时目录执行测试，避免系统Temp的既有权限问题。
.\.venv\Scripts\python.exe -m pytest -q --basetemp=.pytest-tmp

# 使用已核验的冻结文件重新生成免安装演示；不拟合模型。
.\.venv\Scripts\python.exe -m src.offline

# 核对并复用新增2026时间段结果；不同身份或损坏输出会被拒绝。
.\.venv\Scripts\python.exe -m src.temporal_validation

# 核对新增2026来源缓存；正确缓存与协议保持字节不变。
.\.venv\Scripts\python.exe -m src.temporal_fetch
```

确需从快照重建时，先运行 `python -m src.data_pipeline build`。相同原始文件和规则应得到相同样本版本；正常 `audit` 命令只核验已存在的数据包，不清空主表。原始预报缓存缺失时，build 会尝试公开接口；NOAA 原始快照缺失需先从来源清单恢复并核对摘要。

重新训练可显式运行 `python -m src.experiments run --replace`。这会覆盖本地冻结结果；不得因为已经看到测试分数而反复改参数，再把同一测试段写成新独立验证。数据源更新、配置更改或解析规则变更必须保留新版本及原因。

主实验 NumPy 复现检查最大概率误差约 $2.8\times10^{-16}$，验证的是文件和计算一致性，不是新增外部效果验证。实际检查记录见 reports。

## 旧研究入口：最新天气与完整度

本节记录完整研究工作台（`start.ps1`）的“最新天气”页；该工作台现在先显示“搬货决策”标签。以下说明只对应研究工作台的“最新天气”页及旧版免安装演示。新版`index.html` / `start.cmd`的自动更新和缓存规则见上文。旧版免安装演示打开`demo.html#live`，选择杭州萧山或宁波栎社，点击“获取最新数据”。

- 未来7个完整UTC日窗口：ECMWF IFS 0.25°数值预报，从明日UTC日开始，按`(start,end]`累加24小时降水，对应北京08:00至次日08:00；不直接套用冻结概率模型。
- 本年度ERA5背景：日降水与平均温度，截止UTC今天减7日。它补充天气背景，不是新增站点实测；不会进入SSOD标签或模型评估。
- 最新站点覆盖：按原测量码规则核对当前年SSOD，显示最后报告日和最后有效降水日，保留不完整报告和缺行。

Python缓存另存在`runtime/weather`，不进入工程ZIP。原始响应和快照按内容保存，最后原子替换索引；断网、限流或坏响应时保留上次有效缓存。预报超过3小时、背景和站点参考超过24小时会显示过期。HTML缓存保存在浏览器本地，访问受浏览器策略或网络限制时会明确显示失败。清除浏览器缓存会删除自己更新的数据。
