# Scoring and Decision Rules

**Version:** `UT-20261016-v1`. Fix these rules before the first formal participant; do not relax them after seeing results. Accept equivalent wording; do not require terminology memorization.

## Operation T1-T5

| Item | Passing evidence |
| --- | --- |
| T1 Select window | Switch from preset June 2 to 2025-06-01 08:00 |
| T2 Find probability | Point to or read about 67.9% (about 68% is acceptable); 52.5 mm is not the probability |
| T3 Find and explain cost | Find CNY 10 and say it is a hypothetical preparation-cost setting, not actual spending or proven saving |
| T4 Reveal reference | Independently reveal and point to 29.0 mm; do not call the 52.5 mm forecast the reference |
| T5 Find source | Expand source/limitations, identify SSOD reference or its record, and identify one page limitation; no acronym memorization or external link click required |

Record each as I independent, A assisted, F incomplete, or X technically unscorable. Record cumulative completion seconds. At 180 seconds, write “incomplete at 180 seconds,” not a completion time. Early withdrawal records actual stop time, reason, and F. A technical interruption records actual stop time and affected X items; do not write >180 seconds. Completion after 180 seconds is auxiliary observation only.

Main-task success is all T1-T5 = I within 180 seconds. Pointing, operating, or explaining answers is help. Reading the task, neutral encouragement, and pre-start device setup are not help. Finding a control without explaining what hypothetical CNY 10 means does not pass T3.

A technical fault ends first measurement without pausing and resuming. Keep completed items, mark affected incomplete items X, and treat any repair continuation as a retry. If a fault occurs after main-task success, preserve the success and score only affected later items.

## First comprehension Q1-Q6

Use 2 correct, 1 partial/uncertain, 0 incorrect, S voluntary skip, X reached but technically unscorable, C answer contamination, and U not reached. A prompted answer is recorded separately and never promoted to 2. Each question has one first state. If an answered participant later withdraws, preserve answered scores only if withdrawal permission is explicit; otherwise delete the individual record.

| Question | What a 2 must express | 1 example | 0 example |
| --- | --- | --- | --- |
| Q1 Probability object | Chance that reference-day precipitation reaches 25 mm; not shop flooding | Knows rainfall is not flooding but misses the 25-mm event | 67.9% is shop flood chance |
| Q2 Low probability | Event can still occur; no safety/no-rain guarantee; keep monitoring | “Not certain,” without saying an event remains possible | Low probability means it will not happen/safe |
| Q3 Cost | Hypothetical preparation cost, not measured CNY spending or saving | Knows it is a preparation expense but is unsure if it is real | CNY 10 has already been saved |
| Q4 Window | Beijing June 1 08:00 to June 2 08:00 | Knows 24 hours but not endpoints | June 1 midnight to midnight |
| Q5 ERA5 | Reanalysis background, not station label; cannot fill missing reference | Knows sources differ but not substitution rule | ERA5 fills the gap and becomes station observation |
| Q6 Freshness | Points to actual retrieval time and cache status; stale is not latest; retrieval is not initialization/publication | Finds only time or status | Page opens, so weather must be current |

Core understanding passes only when Q1-Q3 are all first-time 2. Q4-Q6 are reported separately and cannot offset a core failure. Q6 need not use the word initialization, but treating retrieval time as forecast publication is not a 2. Q4/Q5 errors still require remediation.

## Denominators and anomalies

Define $N$ as formal participants who consented and actually started the main task. R IDs are internal rehearsal and not $N$. Separate target-relevant and non-target people; retries do not increase $N$ and versions/rounds are reported separately.

- Operation success = independent success within 180 seconds / $N$.
- Core comprehension = first-time Q1-Q3 all correct / $N$.
- Per-question correctness = first-time 2 / $N$; report 0, 1, S, X, C, and U counts too. The seven categories must sum to $N$.
- A retained technical interruption or a participant who exits but explicitly allows retention remains in $N$ and is reported separately; do not call it comprehension failure.
- Full withdrawal, or exit without explicit retention permission, deletes the individual record and removes it from $N$; report the anonymous withdrawal count without scores or quotes.
- If $N=0$, write “not conducted / no records to aggregate,” not 0% or 100%.

Targets are at least 80% for each primary metric. For $N=5,6,7,8$, this means at least 4,5,6,7 people. These are exploratory targets, not significance tests or acceptance guarantees. Report time range and median only for independent successes, with count; list help, timeouts, and interruptions separately.

## Remediation priority

- **High:** treating rainfall probability as flood or official warning, low probability as safety, hypothetical cost as real savings, ERA5 as station label, or old cache as current forecast. Fix wording before giving outward action guidance even if 80% is met.
- **Medium:** cannot find task controls, time boundary, or source.
- **Low:** non-comprehension layout preferences, with reason recorded.

Use a new version after changes and prefer new participants. If returning participants are used, label learning effects. Post-case or post-explanation answers show learning in that session, not first-page understanding. Small samples cannot support population adoption, willingness to pay, or weather-effect claims.
