## Common questions

**Why AI?** The numerical model supplies rainfall input; logistic regression expresses a probability-to-preparation-cost relation. It does not prove new rainfall-ranking ability or fair comparison with every stronger calibrator.

**Is the model better than baseline?** On the same 240 test days, Brier is 0.0455 versus 0.0697 for the training event-rate baseline. The sample and event count are small. The raw 25-mm rule's 0/1 squared-error score, 0.0625, is not a weather-agency probability score.

**Are misses reduced?** At 10%, model misses 6 and false alarms 9; raw rule misses 11 and false alarms 4. Do not report only the favorable side.

**Why not choose the 0.0444 temperature/humidity result?** The method was selected on validation; changing after seeing test results would undermine the held-out test explanation.

**Was 2026 validated?** There is an independent frozen-parameter check, but only 85/273 paired days, one event, and no complete reference April-September. It is not a complete 2026 plum-rain validation.

**Can Ningbo use it?** Public weather can be displayed, but 2025 station-reference precipitation is missing, so there is no transfer evaluation.

**Why not use ERA5 for the gap?** ERA5 is reanalysis context. Replacing a station label with it changes the target and cannot repair the evidence gap.

**How much money is saved?** No real avoided-loss amount is measured. The page assumes complete loss avoidance only to show a relative CNY scenario.

**What is missing?** A completed application, verified judge-accessible URL, team confirmation of media, and real-user evidence. New models and more stations come after the submission loop.
