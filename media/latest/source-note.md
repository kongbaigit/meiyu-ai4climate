# 纯配乐动态文字版来源

本版按要求移除配音，只保留原创器乐配乐，使用12段动态文字解释天气、成本与选择。60秒、1920×1080、30fps、7场景，主时间线使用GSAP 3.15.0；原生Canvas直接创建VideoFrame，经WebCodecs编码后合成H.264/AAC，没有截图或录屏作为影片输入。

天气画面保留2026年10月19日北京时间13:48获取的真实Open-Meteo响应快照，原始文件在source/evidence。51成员含控制成员与50个编号成员；成员占比未经实况校准，不是货损概率。60%和80、600、1000、100元均为标明的算账假设，预计收益不等于已经实现的收益。实际应用继续在线获取最新天气。

数据来源：[Open-Meteo集合预报](https://open-meteo.com/en/docs/ensemble-api)、[控制成员说明](https://github.com/open-meteo/open-meteo/discussions/366)、[数据条款](https://open-meteo.com/en/terms)。GSAP 3.15.0原发行文件及Standard License保留在source/vendor。

原创配乐使用本项目自己的程序合成音色，96 BPM、4/4、24小节、234个事件、4轨MIDI。没有第三方歌曲、人声采样、配音轨或语音合成。移除了原先配音段落的音乐压低，57秒开始自然淡出。可核对的音乐事件、母带摘要与纯器乐声明在source/audio/score_manifest.json。

预览为自包含HTML，只有一个配乐音频元素，可播放、暂停、重播、跳转和调音量。技术检测与实际关键画面检查分别记录，完整主观观看和音乐听审尚待团队确认。系统字体没有随包分发，更换系统后须核对排版。

公开发布状态以项目主README的“在线演示”说明为准。旧配音版保留在Git历史及此前交付目录。
