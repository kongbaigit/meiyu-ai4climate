# 原生动效演示影片

当前影片长2分49秒，1920×1080、30fps，H.264/AAC。三维几何、粒子、文字和图表由代码逐帧绘制，直接送入WebCodecs编码。画面没有使用截图、录屏或外部图片视频。

- demo.mp4：含原创配乐与本地中文合成旁白的成片草稿。
- demo.html：自包含HTML播放器，离线打开即可播放、拖动、跳章节并分别调节旁白与配乐。
- 雨前的刻度.mp3：原创程序合成配乐的独立聆听版本。
- captions.srt、narration.json：字幕与旁白。
- native_source：可编辑的动画、分镜、音符、混音和导出代码；Three.js的MIT许可随源提供。
- render_manifest.json：文件摘要、数据身份、制作方法与真实限制。

旁白使用Windows本地Microsoft Huihui Desktop。音乐的旋律、和弦、节拍与音色由本项目程序合成，未使用第三方音乐素材。三维商铺与数据结构为示意，视频仍需团队确认。
